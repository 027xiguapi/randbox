### Generation Algorithm Implementation

**Basic Generation Logic**
```javascript
class USPhoneGenerator {
    constructor() {
        this.segments = this.loadSegments();
    }

    generate(options = {}) {
        const {
            count = 1,
            state = null,
            carrier = null,
            type = 'Any',
            exclude = []
        } = options;

        const numbers = [];
        for (let i = 0; i < count; i++) {
            const segment = this.selectRandomSegment(state, carrier, type);
            const number = this.formatNumber(segment);

            if (!exclude.includes(number)) {
                numbers.push(number);
            }
        }

        return numbers;
    }

    selectRandomSegment(state, carrier, type) {
        let segments = this.segments.filter(s => s.is_active);

        if (state) segments = segments.filter(s => s.state === state);
        if (carrier) segments = segments.filter(s => s.carrier === carrier);
        if (type !== 'Any') segments = segments.filter(s => s.type === type);

        // Avoid selecting special numbers
        segments = segments.filter(s => {
            const npa = s.npa;
            const nxx = s.nxx;
            return !(npa === '555' || nxx === '555' ||
                    npa === '411' || nxx === '411');
        });

        return segments[Math.floor(Math.random() * segments.length)];
    }

    formatNumber(segment) {
        const npa = segment.npa;
        const nxx = segment.nxx;
        const line = this.generateLineNumber();
        return `+1${npa}${nxx}${line}`;
    }

    generateLineNumber() {
        // Generate subscriber number (XXXX)
        const line = Math.floor(Math.random() * 10000)
            .toString()
            .padStart(4, '0');
        return line;
    }
}
```

## US Laws and Regulations and Compliance Requirements

### TCPA (Telephone Consumer Protection Act)

**Core Provisions**
- Effective date: 1991
- Regulatory agency: FCC (Federal Communications Commission)
- Scope: All commercial communications

**Main Requirements**
1. **Consent Principle**: Must obtain explicit consent from recipient
2. **Time Restrictions**: Cannot call before 8 AM or after 9 PM
3. **Identification**: Must clearly state caller identity
4. **Unsubscribe Mechanism**: Must provide convenient unsubscribe method
5. **Record Retention**: Keep call consent records for at least 4 years

**Violation Penalties**
- Per violation: Up to $500-$1,500
- Class action: Can reach millions of dollars
- Criminal liability: Intentional violations can face imprisonment

### CAN-SPAM Act (Controlling the Assault of Non-Solicited Pornography and Marketing Act)

**Applicable Scenario**: Email marketing
- Requirement: Email content must be truthful
- Regulation: Must provide unsubscribe link
- Penalty: Up to $43,792 per violating email

- Website: donotcall.gov

- Effective time: 31 days after registration
- Permanent: Unless actively canceled

**Exemptions**

### Format Accuracy

**Validation Method**
```javascript
// Format validation function
function validateUSPhoneNumber(number) {
    // Remove all non-numeric characters
    const digits = number.replace(/\D/g, '');

    // Check length
    if (digits.length !== 11 && digits.length !== 10) {
        return false;
    }

    // Check country code
    if (digits.length === 11 && digits[0] !== '1') {
        return false;
    }

    // Extract NPA and NXX
    const startIndex = digits.length - 10;
    const npa = digits.slice(startIndex, startIndex + 3);
    const nxx = digits.slice(startIndex + 3, startIndex + 6);

    // Validate NPA and NXX rules
    if (npa[0] === '0' || npa[0] === '1' ||
        nxx[0] === '0' || nxx[0] === '1') {
        return false;
    }

    // Check special codes
    if (npa === '555' || nxx === '555' ||
        npa === '411' || nxx === '411') {
        return false;
    }

    return true;
}
```
