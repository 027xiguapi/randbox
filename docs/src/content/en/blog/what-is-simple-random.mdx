## In-depth Analysis of Simple Random Sampling

### Core Definition and Mathematical Formulation

**Simple Random Sampling** is a sampling method where n units are selected from a population of N units such that each possible sample has equal probability of being selected.

**Mathematical Definition**:
Let population size be N and sample size be n, then simple random sampling satisfies:

1. **Equal Probability**: Each unit in the population has equal probability of being selected into the sample, all P = n/N
2. **Independence**: Each selection is independent, whether one unit is selected does not affect the selection probability of other units
3. **Randomness**: Each unit's chance of being selected is completely determined by random mechanism

**Combinatorial Mathematics Perspective**:
Total possible samples of selecting n units from population N: `C(N,n) = N! / (n!(N-n)!)`

Each sample's probability of being selected: `1 / C(N,n)`

### In-depth Analysis of Theoretical Characteristics

#### 1. Unbiasedness

**Unbiased Estimation of Population Parameters**

Sample mean is unbiased estimate of population mean:
```
E(x̄) = μ
```

Where:
- `x̄` is sample mean
- `μ` is population mean
- `E()` denotes expected value

**Proof Idea**:
For simple random sampling, each population unit has equal chance of being selected into the sample, so sample mean equals population mean in expectation.

#### 2. Consistency

As sample size n increases, sample statistics converge in probability to population parameters:
```
lim(n→∞) P(|x̄ - μ| > ε) = 0
```

#### 3. Efficiency

Among all unbiased estimates, sample mean from simple random sampling has minimum variance:
```
Var(x̄) = σ²/n × (N-n)/(N-1)
```

Where:
- `Var(x̄)` is variance of sample mean
- `σ²` is population variance
- `(N-n)/(N-1)` is finite population correction factor

```javascript
// Python's Mersenne Twister implementation
class MersenneTwister {
  constructor(seed = Date.now()) {
    this.mt = new Uint32Array(624);
    this.index = 624;
    this.initialize(seed);
  }

  initialize(seed) {
    this.mt[0] = seed >>> 0;
    for (let i = 1; i < 624; i++) {
      this.mt[i] = (1812433253 * (this.mt[i-1] ^ (this.mt[i-1] >>> 30)) + i) >>> 0;
    }
  }

  extractNumber() {
    if (this.index >= 624) {
      this.generateNumbers();
    }

    let y = this.mt[this.index++];
    y ^= y >>> 11;
    y ^= (y << 7) & 0x9d2c5680;
    y ^= (y << 15) & 0xefc60000;
    y ^= y >>> 18;

    return y >>> 0;
  }

  generateNumbers() {
    for (let i = 0; i < 624; i++) {
      let y = this.mt[i] & 0x80000000 + this.mt[(i + 1) % 624] & 0x7fffffff;
      this.mt[i] = this.mt[(i + 397) % 624] ^ (y >>> 1);
      if (y % 2) {
        this.mt[i] ^= 0x9908b0df;
      }
    }
    this.index = 0;
  }

  // Simple random sampling implementation
  simpleRandomSample(population, sampleSize) {
    const shuffled = [...population];
    // Fisher-Yates shuffle
    for (let i = shuffled.length - 1; i > 0; i--) {
      const j = Math.floor(this.extractNumber() / 0xFFFFFFFF * (i + 1));
      [shuffled[i], shuffled[j]] = [shuffled[j], shuffled[i]];
    }
    return shuffled.slice(0, sampleSize);
  }
}
```

```python
import random
import numpy as np

def simple_random_sampling(population, sample_size, seed=None):
    """
    Simple random sampling

    Parameters:
    - population: Population list
    - sample_size: Sample size
    - seed: Random seed (optional)

    Returns:
    - Sample list
    """
    if seed is not None:
        random.seed(seed)

    return random.sample(population, sample_size)
```

```python
def numpy_simple_sampling(population_size, sample_size, seed=42):
    """Simple random sampling using NumPy"""
    np.random.seed(seed)

    # Sampling without replacement
    sample_indices = np.random.choice(
        population_size,
        size=sample_size,
        replace=False
    )

    return sample_indices + 1  # Convert to 1-based numbering
```

### Method 3: Systematic Randomization

**Fisher-Yates Shuffle Algorithm**
```python
def fisher_yates_sample(population, sample_size):
    """Sampling using Fisher-Yates algorithm"""
    population_copy = population.copy()

    # Shuffle process
    for i in range(len(population_copy) - 1, 0, -1):
        j = random.randint(0, i)
        population_copy[i], population_copy[j] = population_copy[j], population_copy[i]

    return population_copy[:sample_size]

# Performance comparison
```

## Sampling Distribution Theory

### Sampling Distribution of Sample Mean

#### When Population Variance is Known

When population variance σ² is known, sampling distribution of sample mean is normal distribution:
```
x̄ ~ N(μ, σ²/n)
```

**Standard Error**:
```
SE = σ/√n
```

#### When Population Variance is Unknown

When population variance σ² is unknown, use sample variance s² for estimation:
```
(x̄ - μ) / (s/√n) ~ t(n-1)
```

Where t distribution has degrees of freedom n-1.

### Sampling Distribution of Sample Variance
```
(n-1)s²/σ² ~ χ²(n-1)
```

Where χ² is chi-square distribution with degrees of freedom n-1.

```python
import pandas as pd
from datetime import datetime, timedelta

class ClinicalTrialRandomizer:
    """Clinical trial random grouping system"""

    def __init__(self, participants, treatment_ratio=1.0, seed=None):
        self.participants = participants
        self.treatment_ratio = treatment_ratio
        self.assignments = {}
        if seed:
            np.random.seed(seed)

    def stratified_randomization(self, strata_columns):
        """
        Stratified random grouping
        """
        # Group by strata
        strata = {}
        for idx, participant in self.participants.iterrows():
            # Create stratum identifier
            stratum_key = tuple(participant[col] for col in strata_columns)
            if stratum_key not in strata:
                strata[stratum_key] = []
            strata[stratum_key].append(idx)

        # Random allocation within each stratum
        for stratum_key, indices in strata.items():
            # Random shuffle
            np.random.shuffle(indices)

            # Calculate number of groups
            total_in_stratum = len(indices)
            treatment_count = int(total_in_stratum * self.treatment_ratio / (1 + self.treatment_ratio))

            # Allocate treatment and control groups
            for i, idx in enumerate(indices):
                if i < treatment_count:
                    self.assignments[idx] = 'treatment'
                else:
                    self.assignments[idx] = 'control'

    def simple_randomization(self):
        """
        Simple random grouping
        """
        participant_indices = list(self.participants.index)
        np.random.shuffle(participant_indices)

        n_treatment = int(len(participant_indices) * self.treatment_ratio / (1 + self.treatment_ratio))

        for i, idx in enumerate(participant_indices):
            if i < n_treatment:
                self.assignments[idx] = 'treatment'
            else:
                self.assignments[idx] = 'control'

    def get_balance_statistics(self):
        """Get grouping balance statistics"""
        assignment_df = pd.DataFrame.from_dict(self.assignments, orient='index', columns=['group'])

        balance_stats = {}
        for col in self.participants.columns:
            if self.participants[col].dtype in ['object', 'category']:
                # Categorical variable
                crosstab = pd.crosstab(assignment_df['group'], self.participants[col])
                balance_stats[col] = crosstab

                # Chi-square test
                chi2, p_value, dof, expected = stats.chi2_contingency(crosstab)
                print(f"{col} - Chi-square test p-value: {p_value:.4f}")

        return balance_stats
```

### Case 3: Manufacturing Quality Control

**Application Scenario**
- Population: Certain batch of products (100,000 items)
- Sampling ratio: 2%

**Quality Control Sampling Implementation**

```python
import pandas as pd
import numpy as np
from scipy import stats

class QualityControlSampler:
    """Quality control sampling system"""

    def __init__(self, batch_size, defect_rate=0.05, seed=None):
        self.batch_size = batch_size
        self.defect_rate = defect_rate
        if seed:
            np.random.seed(seed)

        # Generate simulated batch data
        self.batch_data = self.generate_batch_data()

    def generate_batch_data(self):
        """Generate batch data"""
        # Generate product IDs
        product_ids = [f'P{i:06d}' for i in range(1, self.batch_size + 1)]

        # Generate quality indicators (normal distribution)
        length = np.random.normal(100.0, 0.5, self.batch_size)
        weight = np.random.normal(50.0, 2.0, self.batch_size)

        # Generate defect indicators (based on defect rate)
        is_defect = np.random.choice([0, 1], self.batch_size,
                                    p=[1-self.defect_rate, self.defect_rate])

        # Add some near-limit products (non-defects but quality near boundary)
        near_limit = np.random.choice([0, 1], self.batch_size, p=[0.95, 0.05])
        length[near_limit == 1] += np.random.normal(0, 0.3,
                                                   np.sum(near_limit))

        return pd.DataFrame({
            'product_id': product_ids,
            'length': length,
            'weight': weight,
            'is_defect': is_defect
        })

    def simple_random_sample(self, sample_size):
        """Simple random sampling"""
        sample_indices = np.random.choice(
            self.batch_size,
            size=sample_size,
            replace=False
        )
        return self.batch_data.iloc[sample_indices]

    def estimate_quality_parameters(self, sample_data):
        """Estimate quality parameters"""
        # Estimate defect rate
        defect_rate_est = sample_data['is_defect'].mean()

        # Estimate length mean and standard deviation
        length_mean = sample_data['length'].mean()
        length_std = sample_data['length'].std(ddof=1)

        # Estimate weight mean and standard deviation
        weight_mean = sample_data['weight'].mean()
        weight_std = sample_data['weight'].std(ddof=1)

        return {
            'defect_rate': defect_rate_est,
            'length_mean': length_mean,
            'length_std': length_std,
            'weight_mean': weight_mean,
            'weight_std': weight_std
        }

    def calculate_confidence_intervals(self, sample_data, confidence=0.95):
        """Calculate confidence intervals"""
        alpha = 1 - confidence
        z_score = stats.norm.ppf(1 - alpha/2)

        intervals = {}

        # Confidence interval for defect rate
        p_hat = sample_data['is_defect'].mean()
        n = len(sample_data)
        se_p = np.sqrt(p_hat * (1 - p_hat) / n)
        intervals['defect_rate'] = [
            p_hat - z_score * se_p,
            p_hat + z_score * se_p
        ]

        # Confidence interval for length mean
        length_mean = sample_data['length'].mean()
        length_se = sample_data['length'].std(ddof=1) / np.sqrt(n)
        intervals['length_mean'] = [
            length_mean - z_score * length_se,
            length_mean + z_score * length_se
        ]

        # Confidence interval for weight mean
        weight_mean = sample_data['weight'].mean()
        weight_se = sample_data['weight'].std(ddof=1) / np.sqrt(n)
        intervals['weight_mean'] = [
            weight_mean - z_score * weight_se,
            weight_mean + z_score * weight_se
        ]

        return intervals

# Implement quality control
```

```python
def calculate_sample_size(population_size, margin_error, confidence_level, estimated_proportion=0.5):
    """
    Calculate sample size required for simple random sampling

    Parameters:
    - population_size: Population size
    - margin_error: Margin of error
    - confidence_level: Confidence level
    - estimated_proportion: Estimated proportion

    Returns:
    - Required sample size
    """
    from scipy.stats import norm

    # Z-value
    z_score = norm.ppf((1 + confidence_level) / 2)

    # Infinite population sample size
    n_infinite = (z_score**2 * estimated_proportion * (1 - estimated_proportion)) / (margin_error**2)

    # Finite population correction
    n_finite = n_infinite / (1 + (n_infinite - 1) / population_size)

    return int(np.ceil(n_finite))
```

```python
def bootstrap_simple_random_sample(population, original_sample, n_bootstrap=1000, confidence_level=0.95):
    """
    Bootstrap enhancement of simple random sampling
    """
    bootstrap_means = []

    for _ in range(n_bootstrap):
        # Sampling with replacement
        bootstrap_sample = np.random.choice(original_sample,
                                          size=len(original_sample),
                                          replace=True)
        bootstrap_means.append(np.mean(bootstrap_sample))

    # Calculate bootstrap confidence interval
    alpha = 1 - confidence_level
    lower_percentile = (alpha/2) * 100
    upper_percentile = (1 - alpha/2) * 100

    ci_lower = np.percentile(bootstrap_means, lower_percentile)
    ci_upper = np.percentile(bootstrap_means, upper_percentile)

    # Visualization
    plt.figure(figsize=(12, 5))

    plt.subplot(1, 2, 1)
    plt.hist(bootstrap_means, bins=50, alpha=0.7, edgecolor='black')
    plt.axvline(ci_lower, color='green', linestyle='--', label=f'{confidence_level*100}% CI')
    plt.axvline(ci_upper, color='green', linestyle='--')
    plt.axvline(np.mean(bootstrap_means), color='red', linestyle='--', label='Bootstrap Mean')
    plt.xlabel('Bootstrap Sample Mean')
    plt.ylabel('Frequency')
    plt.title(f'Bootstrap Sampling Distribution (n={n_bootstrap})')
    plt.legend()

    plt.subplot(1, 2, 2)
    plt.hist(original_sample, bins=30, alpha=0.7, edgecolor='black')
    plt.axvline(np.mean(original_sample), color='red', linestyle='--', label='Original Sample Mean')
    plt.xlabel('Original Sample Values')
    plt.ylabel('Frequency')
    plt.title('Original Sample Distribution')
    plt.legend()

    plt.tight_layout()
    plt.show()

    return {
        'bootstrap_mean': np.mean(bootstrap_means),
        'bootstrap_std': np.std(bootstrap_means),
        'confidence_interval': (ci_lower, ci_upper),
        'bias': np.mean(bootstrap_means) - np.mean(original_sample)
    }
```

### 1. Pre-sampling Preparation

```python
class SamplingPlan:
    """Sampling plan formulation"""

    def __init__(self):
        self.objectives = None
        self.target_population = None
        self.sampling_frame = None
        self.sample_size = None
        self.confidence_level = None
        self.margin_error = None

    def define_objectives(self, objectives):
        """Define research objectives"""
        self.objectives = objectives
        return self

    def define_population(self, population_size, population_characteristics):
        """Define target population"""
        self.target_population = {
            'size': population_size,
            'characteristics': population_characteristics
        }
        return self

    def assess_sampling_frame(self, frame_completeness, frame_accuracy, frame_currency):
        """Assess sampling frame quality"""
        # Calculate sampling frame quality score
        frame_score = (frame_completeness + frame_accuracy + frame_currency) / 3

        recommendations = []
        if frame_score < 0.8:
            recommendations.append("Need to improve sampling frame quality")
        if frame_completeness < 0.9:
            recommendations.append("Supplement missing units")
        if frame_accuracy < 0.9:
            recommendations.append("Update unit information")

        return {
            'score': frame_score,
            'recommendations': recommendations
        }

    def calculate_sample_size(self, margin_error, confidence_level, estimated_proportion=0.5):
        """Calculate sample size"""
        self.margin_error = margin_error
        self.confidence_level = confidence_level

        self.sample_size = calculate_sample_size(
            self.target_population['size'],
            margin_error,
            confidence_level,
            estimated_proportion
        )
        return self

    def select_sampling_method(self, population_heterogeneity, cost_constraints, precision_requirements):
        """Select sampling method"""
        methods = []

        # Based on population homogeneity
        if population_heterogeneity == 'high':
            methods.append('Stratified Sampling')

        # Based on cost constraints
        if cost_constraints == 'tight':
            methods.append('Cluster Sampling')

        # Based on precision requirements
        if precision_requirements == 'high':
            methods.append('Simple Random Sampling')

        return methods

    def generate_sampling_protocol(self):
        """Generate sampling protocol"""
        protocol = {
            'research_objectives': self.objectives,
            'target_population': self.target_population,
            'sample_size': self.sample_size,
            'confidence_level': self.confidence_level,
            'margin_error': self.margin_error,
            'estimated_proportion': 0.5,
            'sampling_method': 'Simple Random Sampling',
            'data_collection_plan': 'Structured Questionnaire',
            'quality_control': 'Double Verification',
            'ethical_considerations': 'Informed Consent, Privacy Protection'
        }

        return protocol
```

```python
class QualityControlSampler:

    def __init__(self, population, sample_size, seed=None):
        self.population = population
        self.sample_size = sample_size

            np.random.seed(seed)

        # Log seed
        seed = np.random.randint(0, 2**31)
        np.random.seed(seed)

        # Execute sampling
        sample_indices = np.random.choice(
            len(self.population),
            size=self.sample_size,
            replace=False
        )

        sample = self.population[sample_indices]

        # Log process
        log_entry = {
            'timestamp': datetime.now(),
            'seed': seed,
            'sample_size': self.sample_size,
            'population_size': len(self.population),
            'sample_indices': sample_indices.tolist(),
            'sampling_method': 'simple_random_sampling'
        }
        self.sampling_log.append(log_entry)

        # Various validation indicators can be added here

            'no_duplicate_check': len(np.unique(sample)) == len(sample),
            'within_range_check': all(x in self.population for x in sample)
        }

        return validations

    def audit_trail(self):
        """Generate audit trail"""
```

### 2. Sampling Imbalanced Data

```python
from collections import Counter

def handle_imbalanced_data(X, y, method='undersample', random_state=42):
    """Handle imbalanced data"""
    np.random.seed(random_state)

    counter = Counter(y)
    print(f"Original class distribution: {counter}")

    if method == 'undersample':
        # Simple random undersampling
        minority_class = min(counter, key=counter.get)
        majority_class = max(counter, key=counter.get)

        minority_indices = np.where(y == minority_class)[0]
        majority_indices = np.where(y == majority_class)[0]

        np.random.shuffle(majority_indices)
        selected_majority = majority_indices[:len(minority_indices)]

        indices = np.concatenate([minority_indices, selected_majority])
        np.random.shuffle(indices)

        return X[indices], y[indices]

    elif method == 'oversample':
        # Simple random oversampling
        minority_class = min(counter, key=counter.get)
        minority_indices = np.where(y == minority_class)[0]

        oversample_indices = np.random.choice(minority_indices,
                                            size=counter[majority_class],
                                            replace=True)

        indices = np.concatenate([np.where(y != minority_class)[0], oversample_indices])
        np.random.shuffle(indices)

        return X[indices], y[indices]

# Generate imbalanced data
X_imbalanced, y_imbalanced = make_classification(n_samples=2000, n_features=10,
                                               n_informative=8, n_redundant=2,
                                               n_classes=2, weights=[0.9, 0.1],
                                               random_state=42)

print("=== Imbalanced Data Processing ===")
print(f"Original distribution: {Counter(y_imbalanced)}")

# Undersampling
X_under, y_under = handle_imbalanced_data(X_imbalanced, y_imbalanced, 'undersample')
print(f"After undersampling: {Counter(y_under)}")
```

### Q4: How to verify effectiveness of simple random sampling?

**A**: Multi-dimensional validation methods:

```python
def validate_simple_random_sampling(population, sample, stratify_vars=None):
    """Validate effectiveness of simple random sampling"""

    print("=== Simple Random Sampling Effectiveness Validation ===\n")

    # 1. Sample size validation
    print("1. Sample size check:")
    print(f"   Population size: {len(population):,}")
    print(f"   Sample size: {len(sample):,}")
    print(f"   Sampling ratio: {len(sample)/len(population)*100:.2f}%")
    print(f"   ✓ Sample size meets requirements" if len(sample) == len(set(sample)) else "   ✗ Duplicate samples exist\n")

    # 2. Without replacement check
    print("2. Without replacement sampling check:")
    is_without_replacement = len(sample) == len(set(sample))
    print(f"   Number of unique values: {len(set(sample)):,}")
    print(f"   Total samples: {len(sample):,}")
    print(f"   ✓ Without replacement sampling" if is_without_replacement else "   ✗ With replacement sampling\n")

    # 3. Distribution representativeness test
    if stratify_vars:
        print("3. Distribution representativeness test:")
        for var in stratify_vars:
            if var in sample.columns:
                # Chi-square test
                observed = sample[var].value_counts()
                expected = population[var].value_counts(normalize=True) * len(sample)

                # Ensure index alignment
                all_categories = set(observed.index) | set(expected.index)
                observed_aligned = [observed.get(cat, 0) for cat in all_categories]
                expected_aligned = [expected.get(cat, 0) for cat in all_categories]

                chi2, p_value = stats.chisquare(observed_aligned, expected_aligned)
                print(f"   {var}: χ²={chi2:.3f}, p-value={p_value:.3f}")
                print(f"   {'✓ Distribution consistent' if p_value > 0.05 else '✗ Distribution inconsistent'}\n")

    # 4. Mean bias test
    print("4. Mean bias test:")
    numeric_vars = sample.select_dtypes(include=[np.number]).columns
    for var in numeric_vars[:3]:  # Check first 3 numeric variables
        pop_mean = population[var].mean()
        sample_mean = sample[var].mean()
        bias = abs(sample_mean - pop_mean)
        se = population[var].std() / np.sqrt(len(sample))

        print(f"   {var}:")
        print(f"     Population mean: {pop_mean:.3f}")
        print(f"     Sample mean: {sample_mean:.3f}")
        print(f"     Bias: {bias:.6f}")
        print(f"     Standard error: {se:.3f}")
        print(f"     {'✓ Bias within normal range' if bias < 2*se else '✗ Bias too large'}\n")

    # 5. Variance test
    print("5. Variance homogeneity test:")
    for var in numeric_vars[:3]:
        pop_var = population[var].var(ddof=1)
        sample_var = sample[var].var(ddof=1)
        var_ratio = sample_var / pop_var

        print(f"   {var}:")
        print(f"     Population variance: {pop_var:.3f}")
        print(f"     Sample variance: {sample_var:.3f}")
        print(f"     Variance ratio: {var_ratio:.3f}")
        print(f"     {'✓ Variance homogeneous' if 0.5 < var_ratio < 2.0 else '✗ Variance heterogeneous'}\n")

    # 6. Randomness test
    print("6. Randomness test:")
    # Runs test
    sorted_sample = np.sort(sample[numeric_vars[0]])
    binary_sequence = (sorted_sample > np.median(sorted_sample)).astype(int)

    # Calculate runs
    runs = 1
    for i in range(1, len(binary_sequence)):
        if binary_sequence[i] != binary_sequence[i-1]:
            runs += 1

    # Calculate expected runs
    n1 = np.sum(binary_sequence)
    n2 = len(binary_sequence) - n1
    expected_runs = (2 * n1 * n2) / (n1 + n2) + 1

    print(f"   Runs test:")
    print(f"     Actual runs: {runs}")
    print(f"     Expected runs: {expected_runs:.1f}")
    print(f"     {'✓ Good randomness' if abs(runs - expected_runs) < 2*np.sqrt(expected_runs) else '✗ Possible non-randomness'}\n")

    return {
        'sample_size_ok': True,
        'no_replacement_ok': is_without_replacement,
        'distribution_tests': 'passed' if stratify_vars else 'skipped',
        'bias_within_limits': True,
        'variance_homogeneous': True,
        'randomness_ok': True
    }
```
