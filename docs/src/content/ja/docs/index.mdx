# RandBox ドキュメント

RandBox は様々な種類のランダムデータを生成するための豊富な API を提供する、強力な JavaScript ランダムデータ生成ライブラリです。このドキュメントは RandBox の全機能モジュールと使用法をカバーしています。

## usage - 使用方法

RandBox を様々な環境でインストールして使用する：

1. **[bower.mdx](/ja/docs/usage/bower)** - Bower パッケージマネージャーによるインストールと使用法
2. **[browser.mdx](/ja/docs/usage/browser)** - ブラウザ環境での使用法（シンプル、中級、上級レベル）
3. **[requirejs.mdx](/ja/docs/usage/requirejs)** - RequireJS モジュールローディング方式
4. **[node.mdx](/ja/docs/usage/node)** - Node.js 環境でのインストールと使用（npm、yarn、ES6）
5. **[function.mdx](/ja/docs/usage/function)** - カスタムランダム関数の使用説明
6. **[cli.mdx](/ja/docs/usage/cli)** - コマンドラインツールのインストールと使用法
7. **[seed.mdx](/ja/docs/usage/seed)** - シード機能の詳説（数字、文字列、マルチパラメーターシード）

## basics - 基本データ型

基本データ型生成機能：

1. **[bool.mdx](/ja/docs/basics/bool)** - ランダムブール値を生成、確率指定をサポート
2. **[character.mdx](/ja/docs/basics/character)** - ランダム文字を生成、文字、数字、記号等のオプションをサポート
3. **[falsy.mdx](/ja/docs/basics/falsy)** - JavaScript の falsy 値を生成
4. **[floating.mdx](/ja/docs/basics/floating)** - ランダム浮動小数点数を生成、範囲と精度設定をサポート
5. **[integer.mdx](/ja/docs/basics/integer)** - ランダム整数を生成、最小値と最大値設定をサポート
6. **[letter.mdx](/ja/docs/basics/letter)** - ランダム文字を生成、大小文字制御をサポート
7. **[natural.mdx](/ja/docs/basics/natural)** - 自然数（非負整数）を生成
8. **[prime.mdx](/ja/docs/basics/prime)** - ランダム素数を生成
9. **[string.mdx](/ja/docs/basics/string)** - ランダム文字列を生成、長さ、文字プール、大小文字等の複数のオプションをサポート
10. **[template.mdx](/ja/docs/basics/template)** - テンプレートベースの文字列生成、プレースホルダー置換をサポート

## finance - 金融データ

金融関連データ生成機能：

1. **[cc.mdx](/ja/docs/finance/cc)** - Luhn アルゴリズムに準拠するランダムクレジットカード番号を生成、カードタイプ指定をサポート
2. **[cc_type.mdx](/ja/docs/finance/cc_type)** - クレジットカードタイプ情報を取得、正式名称と略称を含む
3. **[currency.mdx](/ja/docs/finance/currency)** - ランダム通貨コードまたは名称を生成

5. **[dollar.mdx](/ja/docs/finance/dollar)** - ランダムドル額を生成、最大値設定をサポート
6. **[euro.mdx](/ja/docs/finance/euro)** - ランダムユーロ額を生成、最大値設定をサポート
7. **[exp.mdx](/ja/docs/finance/exp)** - クレジットカード有効期限（MM/YY 形式）を生成

9. **[exp_year.mdx](/ja/docs/finance/exp_year)** - クレジットカード有効期限年を生成、2桁または4桁形式をサポート
