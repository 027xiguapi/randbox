# helpers - ヘルパー

実用的なヘルパー機能とデータ操作ツール：

1. **[capitalize.mdx](/ja/docs/helpers/capitalize)** - 単語の先頭文字を大文字にします
2. **[pick.mdx](/ja/docs/helpers/pick)** - 廃止された選択機能。pickone と pickset の使用を推奨
3. **[pickset.mdx](/ja/docs/helpers/pickset)** - 配列から複数のランダム要素を選択します
4. **[pickone.mdx](/ja/docs/helpers/pickone)** - 配列から1つのランダム要素を選択します
5. **[shuffle.mdx](/ja/docs/helpers/shuffle)** - 配列の順序をシャッフルします
6. **[pad.mdx](/ja/docs/helpers/pad)** - 数値のパディング機能
7. **[set.mdx](/ja/docs/helpers/set)** - デフォルトデータセットをオーバーライド
8. **[mixin.mdx](/ja/docs/helpers/mixin)** - RandBoxを拡張するためのミックスイン機能
