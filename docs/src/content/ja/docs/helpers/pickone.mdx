# pickone

```js
// 使い方
randBox.pickone(array)
```

指定された配列からランダムな要素を1つ選択把它们返します

```js
randBox.pickone(['alpha', 'bravo', 'charlie', 'delta', 'echo']);
=> 'delta'
```
