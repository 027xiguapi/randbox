# set

```js
// 使い方
randBox.set(key, value)
```

randBox が使用するデフォルトデータをオーバーライドするために使用します。

例えば、デフォルトの姓集合（これらは米国国勢調査データ來源で、明らかに米国に偏っています）を使用したくない場合、タスクにより適合する内容でデータを置き換えることができます。例えば、「氷と火の歌」の家系の姓から選択したい場合、次のようにします：

```js
randBox.set('lastNames', ['Arryn', 'Baratheon', 'Bolton', 'Frey', 'Greyjoy', 'Lannister', 'Martell', 'Stark', 'Targaryen', 'Tully', 'Tyrell']);

// その後
randBox.last()
=> 'Lannister'
```

これは国際化に非常に便利です。

オーバーライドできるデータセットキー：`firstNames`、`lastNames`、`provinces`、`us_states_and_dc`、`territories`、`armed_forces`、`street_suffixes`、`months`、`cc_types`、`currency_types`
