# template

指定されたテンプレートに一致するランダムな文字列を返します。

```js
// 使い方
randBox.template('{AA####}')
=> 'ZQ7803'
randBox.template('{Aa}-{##}')
=> 'Vr-78'
randBox.template('{####}:{####}:{####}')
=> '1628:5987:7803'
```

テンプレートは、任意の数の「文字置换」と「文字リテラル」のシーケンスで構成されます。「文字置换」シーケンスは左中括弧で始まり、任意の数の特別な置换文字を含み、右中括弧で終了します。文字リテラルは、中括弧またはバックスラッシュ以外の任意の文字にできます。バックスラッシュエスケープを使用して、出力にリテラル中括弧またはバックスラッシュ文字を含めることができます。

以下の置换文字が置换シーケンスで使用できます：

   * "#"：ランダムな1つの数字
   * "a"：ランダムな1つの小文字アルファベット
   * "A"：ランダムな1つの大文字アルファベット
