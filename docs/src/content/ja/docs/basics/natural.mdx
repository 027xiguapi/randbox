# natural

```js
// 使い方
randBox.natural()
randBox.natural({ min: 1, max: 20 })
```

自然数を返します。

_範囲：0 から 9007199254740991_

```js
  randBox.natural();
  => 125019392395
```

必要に応じて min と max を指定できます。

```js
randBox.natural({min: 1, max: 20});
=> 14
```

必要に応じて除外したい数字を指定できます。

```js
randBox.natural({min: 1, max: 5, exclude: [1, 3]});
=> 2
```

これらは包括的であり、範囲内に含まれます。これは、
```randBox.natural({min: 1, max: 3});``` が 1、2 または 3 のいずれかを返すことを意味します：

```js
// 具体情况
1 <= ランダム数 <= 3

// 一般状況
min <= ランダム数 <= max
```
