# currency_pair

```js
// 使い方
randBox.currency_pair()
```

通貨ペアを生成します。通貨変換のシミュレーションに便利です。一意の通貨ペア（同じ通貨が2回返されることはありません）を返すことを保証します。

```js
randBox.currency_pair();
=> [{ code: "ALL", name: "Albania Lek" }, { code: "ZWD", name: "Zimbabwe Dollar" }]
```
